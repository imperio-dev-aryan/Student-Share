# StudentShare

**An Academic Resource Exchange Platform**

StudentShare is a web-based platform designed to make academic resources easier to discover, access, and exchange among students. It brings different types of educational materials together in one place, allowing students to explore resources based on subjects, departments, and semesters.

---

## Overview

Students often rely on multiple sources to find notes, books, study guides, and laboratory manuals. StudentShare aims to simplify this process by providing a centralized platform for academic resources.

The platform organizes resources into dedicated categories and provides filtering, searching, and sorting functionality to help students find relevant materials.

## Features

### 1. Resource Categories

StudentShare currently includes the following main sections:

- **Books:** Explore academic books and reference materials.
- **Notes:** Find subject-specific notes and study materials.
- **Study Guides:** Access revision guides and subject summaries.
- **Lab Manuals:** Explore laboratory manuals for different subjects.
- **Subjects:** Browse subjects according to department, semester, and category.

### 2. Search and Filtering

The resource pages include filtering and search options to help users narrow down available content.

Depending on the page, these include:

- Search by resource or subject name.
- Filter by department.
- Filter by semester.
- Filter by subject.
- Filter by resource type, such as Free or Exchange.
- Sort resources by popularity, rating, date, or name.

### 3. Resource Cards

Resources are displayed in individual cards containing relevant information, such as:

- Resource title.
- Subject and department.
- Semester.
- Resource type.
- Rating and review information.

### 4. User Interface

The website uses a consistent dark-themed interface with:

- Deep navy backgrounds.
- Gold accent colors.
- White primary text.
- Muted secondary text.
- Consistent navigation and resource layouts.

### 5. Navigation

The website includes a shared navigation header with:

- StudentShare branding.
- Search functionality.
- Notification panel.
- Profile section.

Some interface panels are still under development.

## Getting Started

### Prerequisites

You need:

- A modern web browser.
- A code editor such as Visual Studio Code.
- A local development server (recommended).

### Running the Project

1. Clone or download the project repository.
2. Open the project folder in your code editor.
3. Start a local development server.
4. Open the website in your browser.

For Visual Studio Code, you can use the **Live Server** extension to run the website locally.

## Current Development Status

StudentShare is currently under development.

The existing implementation focuses on the website's front-end interface and core interactions.

Some functionality, including notification and profile panels, is still being developed. Bookmark interactions and resource filtering currently operate on the front end; persistent storage and backend integration have not yet been established.
